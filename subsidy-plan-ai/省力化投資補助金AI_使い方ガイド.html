最初に覚えること

このAIは「一度に全部書く」道具ではありません。

資料を先に読み込み、面談前・面談後・追加面談の情報を別々に保存し、確認した内容だけを整理して事業計画書へ使います。

この順番で進めます

  1. 資料・会話記録・Brainデータを読み込む
  2. 面談前の情報として保存
  3. 面談後の確認内容を別保存
  4. 必要なら追加面談を別保存
  5. 整理プレビューを確認して統合
  6. 16項目を順番に作成・保存

実際の画面操作はこの順番です

迷ったら、画面上部の「この案件の進め方」にある番号ボタンを押してください。現在の工程が太く表示され、次にすることが表示されます。

1
「資料読込画面へ」を押す
資料・会話記録・Brainデータを選択します。
次へ進める表示：
「自動抽出結果」が表示されたら、内容を確認します。
2
入力フェーズを「面談前」にする
資料から分かる会社情報・事業内容・設備情報だけを入力します。
次へ進める表示：
「面談前」と日時が保存済みフェーズに表示されます。
3
面談後に同じ案件を開く
入力フェーズを「面談後」に変更し、確認できた課題・ボトルネック・導入効果・数値目標を追記します。
次へ進める表示：
面談前とは別に「面談後」の記録が増えます。
4
必要な場合だけ「追加面談・補足」で保存
追加資料、見積、実施体制など、後から確認した内容を入力します。
注意：
面談前・面談後の記録を編集して消さず、新しいフェーズとして残します。
5
整理するフェーズを1つ選ぶ
「整理プロンプトをコピー」→ ChatGPT等へ貼付→回答を「整理プロンプトへの回答」欄へ貼付します。
次へ進める表示：
回答を確認して「整理回答を確認して基本データへ反映」を押します。フェーズごとに繰り返します。
6
左側の項目を上から順に作成
「現在のプロンプトをコピー」または「現在のプロンプトTXT保存」で、その項目の作成用データを使います。
完了の目印：
回答を貼り付けて「次の項目」を押し、最後に「回答を最終統合」を押します。
画面に「保存済み」が出るまで次へ進まないでください。
保存先・案件名・容量が表示されたら保存確認完了です。保存失敗と表示された場合は、統合や生成を続けず、保存状態を確認します。

各フェーズ内の整理工程

フェーズを選ぶと、そのフェーズ専用の整理欄が表示されます。資料・面談前・面談後・追加面談を混ぜずに一つずつ整理できます。

  1. 入力欄に資料または面談で確認した内容を入れ、「このフェーズを保存」します。
  2. 「このフェーズの整理プロンプトをコピー」で、現在フェーズだけのプロンプトを使います。
  3. ChatGPT等の回答を「整理回答」欄へ貼り付けます。
  4. 「回答を検査」を押し、文字数・重複候補・矛盾候補・要確認件数・出所を確認します。
  5. 確認後に「検査済み回答を基本データへ反映」を押します。反映失敗時は元の基本データを保持します。
  6. 親画面の基本データと保存済み表示を確認してから、次のフェーズへ進みます。

原記録全文はフェーズ記録として残り、基本データには整理回答だけが入ります。事実と未確定、矛盾候補は分け、数値や事実を推測で補いません。

フェーズごとの使い方

PHASE 1　面談前

資料から分かることだけを先に入れる

  • 会社情報、事業内容、過去実績、設備情報を確認します。
  • 推測で補わず、「要確認」の情報はそのまま残します。
  • 保存ボタンを押すと、面談前の記録として別に保存されます。
PHASE 2　面談後

面談で確認した内容を追記する

  • 経営課題、ボトルネック、導入効果、数値目標を入力します。
  • 面談前の記録は上書きされません。
  • 同じ項目の内容が変わった場合は、差分と出所を確認します。
PHASE 3　追加面談・補足

後から分かった情報を別の記録にする

  • 追加確認、資料差し替え、見積・体制の補足に使います。
  • 既存フェーズを編集して消すのではなく、新しい記録として保存します。
  • 必要なフェーズだけを統合対象に選べます。
PHASE 4　整理・統合

確認した情報だけを基本データへ反映する

  • 「整理プレビューを更新」で統合前の状態を確認します。
  • 重複はまとめ、矛盾候補と未確定情報は分けて表示します。
  • 内容を確認してから「基本データへ反映」を押します。

面談前にやること

  1. 「資料読込画面へ」を開きます。
  2. 対象資料を複数選択します。
  3. 自動抽出された内容を確認します。
  4. 入力フェーズを「面談前」にして保存します。
  5. 保存済みの表示とフェーズ名を確認します。

資料の全文を基本データへ貼り付けるのではなく、後の整理工程で項目ごとにまとめます。

面談後にやること

  1. 同じ案件を開きます。
  2. 入力フェーズを「面談後」に切り替えます。
  3. 面談で確認できた内容だけを追記します。
  4. 面談後として保存します。
  5. 必要なら「追加面談・補足」でもう一度保存します。

保存済みフェーズは日時・出所付きで残るため、前の記録を消す必要はありません。

16項目の作成方法

左側の「添付フォーマットの項目順」から、上から順番に進めます。各項目では、現在の見出しに対応するフォーマット部分だけがプロンプトへ入ります。

基本データ整理・確認済みの会社情報、課題、設備、数値など。ここにない事実はAIが作りません。
参考資料公募要領など、制度上の条件・確認観点。
参考フォーマット現在作成する見出しの表・注意書き・文字数目安だけ。
事業計画作成ガイドその項目で何を説明するか、どの観点を確認するか。
回答欄ChatGPT等から返ってきた回答を貼り付け、次の項目へ進みます。

保存について

✓ フェーズ記録は別保存
✓ 前の内容を上書きしない
✓ 事業計画書は案件フォルダへ保存
✓ 同名ファイルは版番号を付ける

通常の利用では、ユーザーが保存ダイアログで保存先を選ぶ必要はありません。画面の保存結果に案件名・保存先・容量が表示されます。

困ったとき

  • 「未確認」が残る → 面談で確認する情報として残します。
  • 内容が重複する → 統合プレビューで整理してから反映します。
  • 矛盾がある → どちらかを勝手に決めず、出所を確認します。
  • 保存失敗と表示される → そのまま進めず、再保存後に表示を確認します。
  • 項目を飛ばした → 左側の項目名から戻って修正できます。
重要な確認

外部支援者や認定支援機関等の助言や作成の支援を受ける場合であっても、実際に事業を実施するのは事業者です。事業者自身が内容を理解し、目標達成できない場合の補助金返還可能性も踏まえ、実行可能な計画であることを確認してから提出用に整えてください。
